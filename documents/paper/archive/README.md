# archive/

Working materials kept around for reference but not part of the build.
Nothing here is referenced by `main.tex`.

- `reviews/` — past review notes and bib audits (`REVIEW*.md`,
  `BIB_AUDIT*.md`).
- `fix/` — older fix-tracking notes (`M2.md`, `M3.md`).
- `scripts/` — one-off helper scripts (`_audit_cites.py`).
- `pdf_renders/` — page screenshots used while iterating on layout
  (`p5*.png`, `p6.png`, `page1.png`).
- `radar_drafts/` — earlier radar-figure renders and the standalone
  TikZ harness (`radar_*.png`, `radar_standalone.{tex,pdf,aux,log}`).
  The radar that ships in the paper lives in
  `../sections/mutation_radar_figure.tex`.
