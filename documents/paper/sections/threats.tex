\section{Threats to Validity}
\label{sec:threats}

\paragraph{Construct.}
Mutation kill rate is only a proxy for real-fault detection.
Equivalent mutants deflate every tool's score alike, so the
cross-tool comparison stays valid, and standard operator sets
keep this bias uniform~\citep{papadakis2019mutation}. Because the
proxy is indirect, we corroborate it directly with the real-bug
benchmark of \S\ref{sec:bug-bench}, which grades detection on
real faults.

\paragraph{Internal: post-audit manifest.}
The $32$-bug manifest reflects a second-pass audit that dropped four
SAM entries failing review and added three htsjdk-SAM regressions
under a tightened verification policy. Neither revision was blinded
to which bugs \biotest{}'s paradigm could reach; we apply the
post-revision predicate uniformly to every tool.

\paragraph{Internal: bug-detection attribution.}
Detection uses the pre-fix/post-fix differential predicate of
\S\ref{sec:bug-bench}. Canary-based
attribution~\cite{hazimeh2020magma} or LAVA-style magic-number
injection~\cite{dolangavitt2016lava} would supersede the predicate
but require per-bug source instrumentation across all four host
languages, which we defer.

\paragraph{Internal: wall-clock vs iteration parity.}
Tools are graded under matched wall-clock budgets, not matched
iteration counts. In-process fuzzers iterate faster than fork-server
ones, visible as a $17$\,pp
AFL++~\citep{fioraldi2020aflpp}~vs~libFuzzer~\citep{libfuzzer2024}
gap on seqan3/SAM under identical mutants and budgets. Iteration
parity would trade one fairness asymmetry for another.

\paragraph{Internal: LLM nondeterminism.}
Phase~B uses a hosted LLM whose sampling is not bit-deterministic,
and the seed-corpus MR validator is not blinded to downstream
performance. We ship the curation log with the artefact as
mitigation.

\paragraph{External.}
The evaluation covers six $(\mathrm{SUT}, \mathrm{format})$ pairs,
two textual formats, and four parser languages. Results do not
extend to checksum-validated binary formats (BCF, BAM, CRAM) where
structural mutations are rejected at I/O time, nor to non-parser
SUTs where the round-trip metamorphic relation does not apply.
