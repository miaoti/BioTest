\subsection{Real-Bug Detection}
\label{sec:bug-bench}

\input{sections/bug_bench_table.tex}

\paragraph{Setup.}
We complement \S\ref{sec:mutation-adequacy} with a Magma-style
ground-truth real-bug
benchmark~\citep{hazimeh2020magma,metzman2021fuzzbench}. The
manifest is $32$ historical parser bugs ($23$ VCF $+ 9$ SAM)
drawn from each SUT's upstream release notes and
\texttt{bug}-label PRs, each pinned to a verified
$V_{\mathrm{pre}}{\to}V_{\mathrm{post}}$ commit pair that ships
a minimum-shape text PoV. A candidate enters iff (i) reachable
through the file-input pipeline, (ii) pre-fix and post-fix
observably differ on the same input, (iii) the anchor pair
reproduces empirically, and (iv) both versions install as a
pinned artefact. Failures are transparently dropped per
standard ground-truth bench protocol. Detection is differential
($\mathit{signal}_T(I, V_{\mathrm{pre}}) \neq
\mathit{signal}_T(I, V_{\mathrm{post}})$ on some input $I$ that
$T$'s adapter produced within a $7200$\,s per-bug budget). The
slate runs eight tools: the five coverage-guided fuzzers of
\S\ref{sec:mutation-adequacy}, \biotest{}, a Pure-Random floor,
and two unit-level Java baselines
(EvoSuite~\citep{fraser2011evosuite} under an
``EvoSuite-anchor'' protocol that synthesises a JUnit suite
against $V_{\mathrm{post}}$ and replays it against
$V_{\mathrm{pre}}$, plus Randoop~\citep{pacheco2007randoop}).
Every input fuzzer's seed corpus contains the manifest's
canonical PoV alongside Tier-1+2 spec-example seeds.

\paragraph{Take-away.}
\biotest{} detects $10/32$ where every other input fuzzer
detects $0/32$. The detections split eight \emph{forward}
regressions (pre-fix rejects, post-fix accepts: htsjdk
stringency edge-cases, vcfpy lazy-evaluation traps, a noodles
writer round-trip) and two \emph{reverse} regressions on htsjdk
(pre-fix wrongly accepts, post-fix rejects: the buggy version
silently mis-classifies or mis-counts a record). Crash-only
oracles surface neither shape without a deliberate
exception~\citep{klees2018fuzz}, which is why every crash-only
fuzzer scores $0$ on every (SUT, format) row.

\paragraph{Unit-level baselines.}
EvoSuite and Randoop bypass file parsing entirely by
constructing parsed-record objects directly via the SUT's
public API, reaching four htsjdk bugs the input-fuzzing slate
does not. One is an API-only builder regression structurally
out-of-scope for any file-input fuzzer. The other three are
parse-time-reachable in principle, but \biotest{}'s
spec-grounded MR transforms in the per-cell budget did not
synthesise a trigger that isolated the patch from co-occurring
spec violations. \biotest{} is nonetheless above both on
absolute count ($10>4>3$). It applies to all four host
languages while EvoSuite and Randoop are Java-only on the
htsjdk row ($12$ of $32$ cells), where \biotest{} still leads
($6/12$ vs $4/12$ vs $3/12$). The differential and metamorphic
oracles also surface silent value-disagreement bugs (e.g.,
mis-counted AC/AN/AF) that neither crash-only fuzzers nor
unit-level GA detect without an external comparator.
