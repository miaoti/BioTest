\subsection{Implementation}
\label{sec:implementation}

\biotest{} is a Python orchestrator. Phase~A indexes the
specification in a ChromaDB vector store with a
sentence-transformer encoder, rebuilt only when the spec version
changes. Phase~B's runs use \texttt{deepseek-v4-flash} via the
DeepSeek API. The orchestrator is provider-agnostic. The prompt
retrieves the top-ranked spec chunks by cosine
similarity~\citep{lewis2020rag} and constrains the model to a
whitelist of $\sim 20$ atomic transforms. Across the headline
runs the per-pair admitted MR count ranges from $3$ on SAM to
$10$ on VCF, with the seed-corpus admission gate as the
load-bearing rejection cause. Figure~\ref{fig:llm-io} traces an
accepted MR end-to-end with real artefacts.

Each SUT's harness runs as a subprocess behind a uniform
interface. Java executes on a per-test JVM with JaCoCo coverage.
Python imports the parser directly with \texttt{coverage.py}.
Rust uses \texttt{cargo test} with \texttt{cargo-llvm-cov}.
C++ is compiled once as a gcov-instrumented binary read by
\texttt{gcovr}. The Corpus Stack's structural enumerator and
lenient byte fuzzer (\S\ref{sec:design-corpus}) ship as
stand-alone generators that are not LLM-mined.

The orchestrator, SUT source pins, mutation engines, coverage
tools, and baseline fuzzers ship as a single Docker image on
Ubuntu~22.04. The C++ mutation engine is a re-implemented
default-operator set rather than upstream
Mull~\citep{denisov2018mull} due to a glibc/Ubuntu version
conflict. The artefact (Docker image digest, source-tree
snapshot, MR-curation log, per-pair raw kill counts and bug-bench
records) is archived on a public repository; the link is
withheld for double-blind review and will be released upon
publication.

\paragraph{Trustworthy LLM deployment.}
\biotest{}'s use of an LLM bound to a validated specification,
with a multi-gate admission pipeline, illustrates a deployment
pattern for trustworthy LLM application in safety-critical
software: the LLM's creative output is bounded by formal validity
gates, so generation quality cannot compromise downstream
correctness.
