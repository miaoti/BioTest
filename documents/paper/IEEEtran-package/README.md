# IEEEtran-package/

Auxiliary files shipped with the IEEEtran BibTeX package. They are
not required for the current build (the build uses the `IEEEtran.cls`
and `IEEEtran.bst` pinned at the paper root, plus the local
`biotest.bib`), but are kept here for reference.

- `IEEEtran_bst_HOWTO.pdf` — official IEEEtran BibTeX style guide.
- `IEEEabrv.bib`, `IEEEfull.bib` — IEEE journal-name string macros
  (abbreviated and full forms) used when a `.bib` file references
  IEEE journals via the `IEEE_J_*` macros.
- `IEEEexample.bib` — example bibliography distributed with the
  IEEEtran style.
- `IEEEtranS.bst` — sortless variant of the IEEEtran BibTeX style.
- `README` — original IEEEtran package README.
